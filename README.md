# Mun Vaasal (முன் வாசல்) 🪔

> **Mun Vaasal** is an interactive digital South Indian Kolam / Rangoli studio built for Hack Club Embassy.

## 🌟 Overview
Traditionally drawn at the entrance of homes each morning using rice flour, *Kolam* represents welcome, positivity, and mathematical symmetry. **Mun Vaasal** brings this age-old threshold art into a modern mobile web experience using dot-grid (*Pulli*) algorithms, interactive touch drawing, and procedural generation.

## 📱 Features
- **Touch Canvas Engine:** Swipe or tap across dot grids (*Pulli*) seamlessly on mobile screens.
- **Procedural Generator:** Instantly weave geometric loops with procedural algorithms.
- **Heritage Color Themes:** Toggle between Terracotta Heritage, Night Indigo, and Sacred Emerald styling.
- **Mobile-First Design:** Fully lightweight, responsive single-file architecture.

## 🛠️ Tech Stack
- **HTML5 Canvas:** Real-time geometric rendering
- **CSS3 Variables:** Dynamic theme switching
- **JavaScript (Vanilla):** Touch gesture calculations & procedural loop logic
- **GitHub Pages:** Automated deployment
